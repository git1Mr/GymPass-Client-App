# Unity Fitness — Mobile UI Kit

High-fidelity recreation of the GymPass member app (React Native + Expo) as click-thru HTML.

## Files
- `index.html` — interactive prototype (login → home → explore → plans → QR pass → profile)
- `ios-frame.jsx` — device frame
- `app.jsx` — root prototype + screen routing + fake auth/state
- `screens.jsx` — Splash, Login, Home, Explore, Plans, Profile, QRPass
- `components.jsx` — Header, TabBar, PrimaryButton, FormInput, StatCard, PillCard, PlanCard, GymCard, HeroCard, BottomSheet
- `data.js` — seed data (gyms, plans, user)

Renders inside an iOS frame at 390×844. Uses Inter (substituted for system font) and Lucide icons (substituted for Ionicons).
